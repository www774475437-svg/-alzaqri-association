# جمعية آل الزوقري الخيرية

تطبيق الجمعية (موقع + APK أندرويد).

- `web/` ملفات التطبيق. `web/content.json` محتوى الجمعية (الأخبار، المشاريع، التقرير المالي…). `web/config.js` روابط الدفع.
- كل دفع إلى `main` يبني الـAPK وينشر الموقع تلقائياً.
- مفتاح التوقيع في `signing/` مفتاح تجريبي للنسخ الأولى فقط.
